# BrightNestCleaning-

BrightNest Cleaning UK is a responsive, Vercel-configured React and Tailwind website for domestic and specialist cleaning services in Birmingham and surrounding areas. It includes the public service price guide and a frontend booking-request journey.

## Run locally

Install dependencies with `pnpm install`, then start the development server with `pnpm dev`.

## Production build

Run `pnpm build`. The generated static site is placed in `dist/public`.

## Vercel deployment

The included `vercel.json` sets the build command, static output directory and SPA route fallback. Import this GitHub repository into Vercel and deploy using the existing configuration.

## Booking integration

The current booking flow is a polished frontend experience. Connect it to a backend, email/WhatsApp notifications, live availability and payments when those operational details are ready.
