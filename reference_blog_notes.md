Observed public navigation: Home, About us, Services, Blogs, Contact, phone CTA, and Book a Cleaning CTA. BrightNest implementation constraint: use only the information architecture and high-level interaction cues. Do not copy Martilla’s logo, text, exact imagery, URLs, layout styling, or brand assets.
