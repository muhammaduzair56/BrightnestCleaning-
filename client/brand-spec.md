# Vellora Logo and SEO Metadata Rollout

- **Master wordmark:** `public/vellora-cleaning-logo.webp` — user-provided WebP, 680 × 226 px, transparent background, 28,790 bytes. Preserve its approximately 3:1 aspect ratio; do not stretch or crop it.
- **Logo placements:** Home, Services, Blog, Dashboard, Admin, Privacy Policy, Terms of Service and 404 screens use the local master wordmark. Favicon/Apple touch/PWA icons use transparent square variants with the complete logo proportionally fitted.
- **SEO and discovery metadata:** Static default title/description/author, Open Graph and Twitter tags, per-route titles/descriptions, Organization/Service/Blog JSON-LD names, PWA display name, AI catalogs and `llms.txt` identify the brand as Vellora Cleaning. Social metadata uses the exact Vellora wordmark as its image to avoid the old BrightNest social card.
- **Domain decision:** Live `https://brightnestcleaning.vercel.app` redirects to `https://velloracleaning.vercel.app`, so the active redirect destination is used as the canonical origin. If a future custom domain is finalized, update canonical URLs, sitemap/robots, structured data, AI catalogs and links together.
- **SEO rendering limitation:** Route-specific metadata is applied after the React SPA loads; raw initial HTML contains shared Vellora defaults. Server/static-rendered route content and a true HTTP 404 for unknown routes remain separate technical work.
- **Scope boundary:** This is a logo and metadata rebrand only. Visible business copy, legal-policy/terms body text, contact email, copyright text and the existing palette remain unchanged pending full rebrand and legal-detail review. The old BrightNest social-preview JPEG remains in the repository but is no longer referenced by share metadata.
- **Social image note:** The master wordmark is 680 × 226 (3:1). Platforms may letterbox or crop it in large social-card layouts; a dedicated Vellora 1200 × 630 share card would improve preview presentation later.
